## About This Repository

This repository contains beginner-friendly Arduino projects covering:

- Basic GPIO control
- Sensor interfacing (LDR, MQ-6)
- PWM (Pulse Width Modulation)
- Serial communication
- Button input handling
- LED effects and sequencing

## Requirements

- Arduino IDE
- Arduino board (Uno/Nano recommended)
- Basic electronic components (LEDs, resistors, breadboard, jumper wires, sensors, etc.)

## Getting Started

1. Install Arduino IDE
2. Clone/download this repository
3. Open any project's `.ino` file in Arduino IDE
4. Connect your Arduino board
5. Upload the code
6. Enjoy!

Each project folder has its own detailed README with pin configurations and explanations.
