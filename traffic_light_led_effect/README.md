# Traffic Light LED Effect

An Arduino project that simulates a traffic light sequence with red, yellow, and green LEDs.

## Components Used
- Arduino (Uno/Nano)
- Red LED
- Yellow LED
- Green LED
- Breadboard & Jumper Wires

## Pin Configuration
| Component         | Arduino Pin |
|-------------------|-------------|
| Red LED           | D7          |
| Yellow LED        | D8          |
| Green LED         | D9          |

## Features
- Realistic traffic light sequence
- Red: 3 seconds
- Yellow: 1 second
- Green: 3 seconds

## How It Works
1. Red LED ON for 3 seconds (Stop)
2. Yellow LED ON for 1 second (Prepare)
3. Green LED ON for 3 seconds (Go)
4. Repeats continuously
