# USB Communication with Serial Monitor

An Arduino project that demonstrates serial communication - reads messages from serial monitor and echoes them back.

## Components Used
- Arduino (Uno/Nano)
- USB Cable

## Features
- Reads serial input until newline
- Stores received message
- Echoes message back to serial monitor
- Simple bidirectional communication

## How It Works
1. Send a message from Serial Monitor
2. Arduino reads the message
3. Arduino echoes the message back
4. Repeats continuously

## Usage
1. Open Serial Monitor (9600 baud)
2. Type a message and press Enter
3. Watch the message echo back!
